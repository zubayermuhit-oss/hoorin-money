HOORIN MONEY — INSTALLABLE PWA

Features: dark green/black UI; dashboard; daily income, expense and transfer tracker; wallets/cards; multi-currency with editable rates; categories and monthly budgets; loans and dues; product prices; monthly summary; CSV export compatible with Excel; print/save-to-PDF; offline app shell and phone-only localStorage.

IMPORTANT: A ZIP cannot be installed directly as an app. PWA install needs a secure HTTPS website.

Install using only your phone:
1. Extract this ZIP using your phone's Files app or a ZIP manager.
2. In Chrome, open https://github.com and sign in/create account.
3. Create a repository named hoorin-money.
4. Upload index.html, manifest.webmanifest, sw.js, and the icons folder to the repository root.
5. Repository Settings > Pages > Deploy from a branch > main > /(root) > Save.
6. Wait for the published HTTPS URL, usually https://YOUR-USERNAME.github.io/hoorin-money/.
7. Open that URL in Chrome, let it load once, then Chrome menu ⋮ > Install app or Add to Home screen.

Data stays in this phone's browser local storage only. There is no cloud sync. Clearing Chrome/site data or uninstalling can erase records. Export CSV regularly for backup. Currency rates are editable sample values. The PDF option uses the browser print dialog where supported. Test with sample data first.
